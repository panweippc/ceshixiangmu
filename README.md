# 宿舍管理系统（前端演示版）

纯静态前端页面，无任何后端依赖。用于演示 / 测试 Git 多人协作开发流程。

## 功能

- **首页**：系统欢迎语、统计卡片（房间数 / 入住人数 / 空床位 / 报修待处理）、最近动态、快捷入口。
- **基础信息**：宿舍列表、学生列表（标签切换）。

## 目录结构

```
.
├── index.html              # 首页
├── basic-info.html         # 基础信息页
├── assets/
│   ├── css/style.css       # 公共样式
│   └── js/
│       ├── data.js         # 本地示例数据（改这里即可改内容）
│       ├── home.js         # 首页渲染逻辑
│       └── basic-info.js   # 基础信息页渲染逻辑
└── README.md
```

## 本地预览

直接用浏览器打开 `index.html` 即可，无需启动任何服务。

## 协作说明（Git 多人开发演示）

本仓库故意拆成多个互不耦合的文件，便于多人并行开发、减少合并冲突：

- 改样式 → `assets/css/style.css`
- 改示例数据 → `assets/js/data.js`
- 改首页逻辑 → `assets/js/home.js`
- 改基础信息页 → `assets/js/basic-info.js`

建议每人从独立分支开发，再合并到 `main`。
